# Python-------Advance-calculator-project
<pre>A menu-driven calculator application developed using Python. This project performs Addition, Subtraction, Multiplication, Division, Power, and Modulus operations while maintaining a calculation history and operation counter. It demonstrates the use of loops, conditional statements, lists, user input handling, and error management.</pre>

## Features
<pre>
- Addition
- Subtraction
- Multiplication
- Division
- Power Calculation
- Modulus Operation
- Calculation History
- Clear History
- Reset Counter & History
- Division by Zero Handling
</pre>
